# In-game logo assets

These SVGs are unmodified copies from `../redot_brand/`:

- `redot_wordmark.svg`: horizontal red-orange logo and wordmark, no outline.
- `redion.svg`: red-orange Redion logo, no outline.
- `redion_outline.svg`: white outline-only Redion logo.

The complete original kit is retained but excluded from automatic engine import
to avoid importing every unused high-resolution variant. See `../ATTRIBUTION.md`.
